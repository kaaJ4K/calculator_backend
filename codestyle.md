# Code Style Guide

## Overview

This document describes the coding style and development conventions used in the backend project.

The backend follows Python standard coding practices to improve readability, maintainability, and consistency.


---

# Python Style

## PEP 8

Python code follows the PEP 8 style guide.

The code should maintain:

- Clear indentation
- Reasonable line length
- Meaningful naming
- Proper spacing


---

# Naming Conventions


## Files

Python files use lowercase names.

Examples:
app.py
calculator.py
database.py


---

## Variables

Variables use snake_case naming.

Examples:

```python
expression_result

calculation_history
