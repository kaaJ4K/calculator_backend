# Calculator Backend

## Introduction

This project is the backend service of a front-end and back-end separated calculator system.

The backend is responsible for:

- Expression parsing
- Calculation
- Input validation
- Error handling
- Database persistence
- History management


## Technology Stack

- Python 3.14
- Flask
- SQLite
